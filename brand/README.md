# Awaaz brand

A sharp "A" with an escalation arrow rising through it and sound-wave rings behind it: a resident's voice, pushed upward until it's heard.

| File | Use |
|---|---|
| `awaaz-logo-color.png` / `-transparent.png` | Full logo (mark + AWAAZ + آواز) on white or light backgrounds |
| `awaaz-logo-on-green.png` / `-transparent.png` | Full logo on flag green or dark backgrounds |
| `awaaz-mark.svg` | Mark only, navy and orange, for light backgrounds |
| `awaaz-mark-on-green.svg` | Mark only for flag green (the app sidebar) |
| `awaaz-mark-navy.svg` | Single-color navy version (one-color printing, stamps) |
| `awaaz-app-icon.svg`, `awaaz-icon-256.png`, `awaaz-favicon-64.png` | App icon, browser tab, social profile. Simplified: no rings, bolder arrow |

Colors: navy `#1B2A4A`, orange `#F47B20`, flag green `#01411C`, white.
Type: Archivo ExtraBold (AWAAZ), Noto Nastaliq Urdu Bold (آواز).
Use the icon below 48 px; the rings are too fine to read at that size. Keep clear space around the logo equal to the height of the A's crossbar.
